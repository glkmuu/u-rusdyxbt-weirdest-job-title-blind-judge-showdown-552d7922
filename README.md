# Weirdest Job Title: Blind Judge Showdown

## Entry

Senior Penguin Relocation Specialist

## Why this title

A "Senior ... Specialist" sounds like a perfectly ordinary corporate job
title — until you notice the thing being relocated is penguins. The twist
is one specific, vivid image: a suited professional whose entire career
is moving penguins from one place to another, presumably with a clipboard
and a relocation budget. It reads instantly, pictures a real person doing
a real-sounding job, and lands the joke on the first read.

## How to run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` and to `entry.txt` next to
`main.py`, with no trailing newline.
